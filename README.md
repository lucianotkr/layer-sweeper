# LAYER SWEEPER

[Play LAYER SWEEPER](https://lucianotkr.github.io/layer-sweeper/)

A 60-second layered Minesweeper rush by Lucy_jackso.

Open safe blocks, disarm mines, and dig deeper. Share your score on X from the result screen!

This repository contains the playable Web build. Development sources and original asset packages are maintained separately. Credits and asset attribution are available inside the game.
